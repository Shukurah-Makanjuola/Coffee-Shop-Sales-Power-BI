# Coffee Shop Sales Dashboard (Power BI)

This project analyzes coffee shop sales data across three store locations to uncover revenue trends, product performance, and category insights.

## Key Insights
- $698.81K revenue from 149K sales
- Steady revenue growth from January to June
- Coffee and Tea drive the highest sales volume
- Barista Espresso generates the highest revenue
- Balanced performance across all stores
